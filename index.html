🛠 วิธีเพิ่มบล็อกวิชาใหม่ หรือเพิ่มโจทย์ด้วยตัวเอง

เว็บไซต์นี้ออกแบบโครงสร้างแบบ Modular เพื่อให้คุณสามารถเพิ่มวิชาใหม่ (เช่น Backend, Python, SQL, React) หรือเพิ่มโจทย์ใหม่ในอนาคตได้ง่ายมาก:

1. เพิ่มบล็อกวิชาใหม่ (Subject Block)

เปิดไฟล์ js/data/subjects.js แล้วเพิ่ม Object วิชาใหม่เข้าไปใน Array SUBJECTS โดยกำหนด id, title, description, และสถานะ status: 'available'

2. เพิ่มโจทย์และ Test Cases

เปิดไฟล์ js/data/frontend-problems.js (หรือสร้างไฟล์ข้อมูลวิชาใหม่) แต่ละโจทย์ประกอบด้วย:

{
  id: 'custom-01',
  moduleId: 'mod-1',
  title: 'ชื่อโจทย์ของคุณ',
  difficulty: 'พื้นฐาน', // พื้นฐาน | ปานกลาง | ใช้งานจริง
  description: 'คำอธิบายโจทย์...',
  requirements: ['เงื่อนไขที่ 1', 'เงื่อนไขที่ 2'],
  starterCode: { html: '...', css: '...', js: '...' },
  hints: ['คำใบ้ที่ 1', 'คำใบ้ที่ 2'],
  solution: { html: '...', css: '...', js: '...' },
  testCases: [
    {
      name: 'ชื่อการทดสอบที่ 1',
      run: ({ win, doc }) => {
        // ตรวจสอบค่าจากฟังก์ชัน หรือ DOM
        const result = win.myFunction(5);
        return { passed: result === 10, expected: 10, actual: result };
      }
    }
  ]
}

3. จัดการข้อมูลความคืบหน้า (Backup / Reset Progress)
